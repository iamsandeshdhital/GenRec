API Documentation

GenRec REST API Reference

GET /api/health

Health check endpoint.

{
  "status": "healthy",
  "cache_size": 5,
  "metrics": { ... }
}

GET /api/metrics

Get serving metrics.

POST /recommend

Generate recommendations for a user.

Request Body

{
  "user_data": { ... },
  "interactions": [ ... ],
  "candidates": [ ... ],
  "context": { ... }
}

Response

{
  "recommendations": ["item_1", "item_2"],
  "scores": { "item_1": 1.0, "item_2": 0.95 },
  "latency_ms": 2.03,
  "cache_hit": false
}

POST /api/evaluate

Evaluate rankings against relevance grades.
